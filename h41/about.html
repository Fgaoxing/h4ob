Philosophy

开发理念 / Philosophy

  • 代码首先是给人看的，其次才是给机器跑的 / Code is for humans first, machines second
  • 好的架构是演化出来的，不是设计出来的 / Good architecture evolves, it's not designed upfront
  • 爱造轮子，复用之前先理解原理 / Love building from scratch, understand before reusing
  • Benchmark 说话，直觉会骗人 / Let benchmarks speak, intuition can lie
  • 预编译优于解释，零拷贝优于反射 / Precompile over interpret, zero-copy over reflection
  • 前端哲学：无依赖、极小体积、高性能 / Frontend: no deps, minimal size, high performance
  • 文档和代码一样重要，甚至更重要 / Documentation matters as much as code, sometimes more
